# PRD: 위험 소리 감지 알림 앱 (Android) v0.7

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.7 |
| 작성일 | 2026-10-30 |
| 상태 | Draft |
| 변경 사항 | 사용자 요청에 따라 아기 울음 제외, 유리 깨짐·문 두드림 추가(총 6종) |

---

## 1. 문제
청각장애인이 화재경보, 초인종, 유리 깨짐, 문 두드림, 차량 경적, 사이렌 같은 소리를 놓쳐 위험하거나 불편을 겪습니다.

## 2. 목표
- 대상 소리 6종을 감지해 **진동과 화면으로 즉시 알린다**
- 소리 발생 후 **3초 이내** 알림
- 오탐은 **시간당 3회 이하** (소리 종류별 내부 기준값으로 튜닝 후 재측정)

## 3. 범위

**MVP 포함**
- 감지 대상 6종 (고정)
  - 집 안: 화재경보, 초인종, 유리 깨짐, 문 두드림
  - 외출: 차량 경적, 사이렌
- 중앙의 큰 시작/종료 버튼
- 상태별 메인 화면 (대기 중, 감지됨, 꺼져 있음)
- 진동 알림 (소리 종류별 패턴)
- 동시 감지 소리 표시 (위험도 순, 최대 3개)
- 백그라운드 감지 (Foreground Service, 감지 중일 때만 동작)
- 권한 안내 화면 (첫 실행 시 1회)

**MVP 제외**
- 소리별 on/off 설정 및 설정 화면
- 민감도 조절
- 알림 기록 조회
- 재부팅 후 자동 재개
- 웨어러블 연동
- 클라우드 전송
- iOS 지원
- 음성 안내
- 가스 경보
- 아기 울음(2026-10-30 사용자 요청으로 제외)

## 4. 사용자
- 농인 및 난청인
- 주 사용 상황: 집 안, 수면 중, 외출 중

## 5. 화면 구성

| 화면 | 구성 |
|---|---|
| 권한 안내 | 권한 허용 버튼 2개, 시작하기 버튼, 고지 문구 |
| 메인 | 상태 표시 영역(상단), 시작/종료 버튼(중앙), 감지 대상 목록(하단) |

### 메인 화면 상태

| 상태 | 배경색 | 상태 텍스트 | 버튼 |
|---|---|---|---|
| 꺼져 있음 | 회색 | "꺼져 있음" | 시작 |
| 정상 대기 중 | 초록 | "✓ 정상 대기 중" | 종료 |
| 감지됨 | 빨강 | "⚠ 화재경보 감지" (동시 감지 시 최대 3개) | 종료 |

## 6. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 주변 소리를 기기 안에서 분류해 대상 6종을 감지한다 | Must |
| FR-02 | 감지 시 진동으로 알린다 (소리 종류별 패턴 상이) | Must |
| FR-03 | 감지 시 화면 배경을 빨강으로 바꾸고 소리 이름을 텍스트로 표시한다 | Must |
| FR-04 | 동시에 감지된 소리는 위험도 순으로 최대 3개까지 표시하고, 초과분은 "외 N건"으로 표시한다 | Must |
| FR-05 | 감지되지 않는 소리는 마지막 감지 후 3초가 지나면 표시 목록에서 제거한다 | Must |
| FR-06 | 감지됨 상태는 10초 후 자동으로 정상 대기 중(초록)으로 복귀한다 | Must |
| FR-07 | 감지됨 상태에서 화면을 탭하면 즉시 정상 대기 중으로 복귀한다 | Must |
| FR-08 | 시작 버튼으로 감지를 시작하고, 종료 버튼으로 감지를 멈춘다 | Must |
| FR-09 | 감지 중에는 상단에 고정 알림을 표시하고(알림에 "종료" 버튼 포함), 종료 시 사라진다 | Must |
| FR-10 | 감지가 예기치 않게 멈추면 사용자에게 알린다 | Must |
| FR-11 | 권한이 없으면 필요한 이유를 안내하고 설정 화면으로 이동시킨다 | Must |
| FR-12 | 상태는 색상, 아이콘, 텍스트를 함께 사용해 표시한다 | Must |
| FR-13 | 각 모델의 6종 점수를 모델·소리별 내부 배율과 보정치로 0~1 범위에 변환한 뒤, 보정 점수 3개의 동일 가중치 평균으로 감지 여부를 판정한다. 보정 계수 초기값은 배율 1·보정치 0이며 실측으로 조정한다 | Must |

## 7. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 개인정보 | 오디오를 저장하거나 서버로 보내지 않는다 |
| 배터리 | 감지 중 하루 배터리 소모 5% 이하 |
| 지원 환경 | Android 8.0 (API 26) 이상 |
| 접근성 | TalkBack으로 상태와 감지 소리 이름을 한 문장으로 읽는다. 색상에만 의존하지 않는다 |
| 안정성 | 감지 중 크래시 없이 24시간 이상 동작 |

## 8. 사용자 흐름
1. 설치 후 권한 안내 화면에서 권한 허용
2. 메인 화면에서 중앙의 **시작** 버튼을 누름 → 초록 배경, 고정 알림 표시
3. 대상 소리 감지 → 빨강 배경, 소리 이름 표시, 진동
4. 10초 경과 또는 화면 탭 → 초록 배경으로 복귀
5. **종료** 버튼을 누름 → 회색 배경, 고정 알림 제거

## 9. 인수 조건 (핵심만)
- 감지 시작 후 화재경보 재생 시 3초 이내 진동과 빨강 배경 전환이 발생한다
- 차량 경적과 사이렌이 동시에 재생되면 두 이름이 모두 표시된다
- 유리 깨짐과 문 두드림 각각 감지 시 해당 이름과 진동이 표시된다
- 아기 울음 점수만 높을 때는 알림이 발생하지 않는다
- 6종이 동시에 감지되어도 위험도순 최대 3개만 표시되고 "외 3건"이 표시된다
- 감지 후 10초가 지나면 초록 배경으로 돌아간다
- 빨강 상태에서 화면을 탭하면 즉시 초록 배경으로 돌아간다
- 감지가 끝난 소리는 마지막 감지 후 3초가 지나면 목록에서 사라진다
- 종료 버튼을 누르면 감지가 중단되고 고정 알림이 사라진다
- 고정 알림의 "종료" 버튼을 눌러도 감지가 중단되고 알림이 사라진다
- 감지 중 앱을 종료해도 Foreground Service 알림이 유지되고 감지가 계속된다
- 마이크 권한을 거부하면 감지가 시작되지 않고 안내가 표시된다

| 단계 | 기간 |
|---|---|
| 감지 모델 검증 (완료로 가정) | - |

## 11. 리스크

| 리스크 | 대응 |
|---|---|
| 특정 소리의 오탐이 잦아 사용자가 감지 전체를 끄는 상황 | 소리별 내부 기준값 튜닝, 베타 테스트에서 불만 확인 후 필요 시 토글 재도입 검토 |
| 동시 감지로 화면이 빨강으로 자주 바뀌어 불안감 증가 | 알림 빈도 제한, 실기기 검증에서 체감 확인 |
| 상시 마이크로 인한 배터리 소모 | 실기기 측정 후 감지 주기 조정 |
| 6종 중 일부 정확도 미달 | 미달 소리는 v1.0으로 이동하는 기준을 미리 정함 |
| 사용자가 종료를 잊고 감지가 꺼진 줄 모름 | 고정 알림과 회색/초록 배경으로 감지 상태를 항상 표시 |
| 안전 책임 범위 | 앱 내 "보조 도구" 고지 문구 추가 |

## 확인이 필요한 가정
- **빨강 자동 복귀 10초**: 제안값입니다. 사용자 테스트로 조정합니다.
- **최대 3개 표시, 3초 제거 규칙**: 제안값입니다.
- **위험도 순서** (화재경보 → 사이렌 → 유리 깨짐 → 초인종 → 문 두드림 → 차량 경적): 임의로 정한 값이므로 사용자 테스트에서 확인합니다.
- **소리별 진동 패턴**: 제안값입니다(화재경보 긴 3회, 사이렌 긴-짧-긴, 유리 깨짐 빠른 3회 후 긴 1회, 초인종 짧은 2회, 문 두드림 일정 간격 3회, 차량 경적 긴 1회). 같은 소리가 이어져도 처음 한 번만 울립니다. 실기기에서 구분감을 확인하고 조정합니다.
- **소리별 기준값**: 잠정값입니다(차량 경적 0.3, 나머지 0.5). 기존 5종 구성에서 ESC-50 음원으로 사이렌, 아기 울음, 차량 경적을 측정했습니다. 현재 6종 구성의 유리 깨짐·문 두드림 기준값도 잠정값이며, 화재경보·초인종을 포함한 실기기 감지율과 오탐률 검증이 필요합니다.
- **수치 목표(3초, 3회/시간, 5%)**: 실기기 검증 전 임시값입니다.
- **일정 4~5주**: 1인 또는 소규모 팀 기준 추정입니다.
