|---|---|

## 사용 방법
- 각 스토리는 PRD의 요구사항 ID(FR, 인수 조건)와 연결되어 있습니다.
- **Ready**: 바로 착수 가능
- **Done(가정)**: 기술 검증 완료로 가정한 항목
- 우선순위는 MoSCoW 기준입니다.

## 변경 이력 (v0.6 → v0.7)
- BL-006 감지 대상에서 아기 울음을 제외하고 유리 깨짐·문 두드림을 추가(총 6종)
- BL-008 소리별 진동, BL-010 동시 감지 6종의 초과 표시, BL-015 접근성 표시 조건에 새 소리 반영
- BL-001 기술 검증 완료 가정은 새 6종의 실측 완료를 뜻하지 않으며 추가 검증 필요

## 변경 이력 (v0.5 → v0.6)
- 설정 에픽(E4)과 소리별 on/off 스토리 삭제
- 감지 결과 표시 에픽(E3) 신설: 빨강 전환, 최대 3개 표시, 자동 복귀, 탭 복귀
- 번호 체계 재정렬 (기존 BL-001~027 → BL-001~028)
