# 모델별 감지율 검사 (BL-001, BL-003, BL-006)

> 이전 5종 구성의 이력이다. 현재 6종(아기 울음 제외, 유리 깨짐·문 두드림 추가)
> 모델 결과는 `tools/model_evaluation/report.json`에 별도로 기록한다.

2026-10-30에 앱에 포함된 실제 TFLite 파일 3개와 동일 가중치 평균 조합을
PC의 TensorFlow 2.21.0에서 실행했다. 실기기 마이크 측정 결과는 아니다.

## 감지율

| 모델 | 사이렌 | 아기 울음 | 차량 경적 |
|---|---:|---:|---:|
| YAMNet | 38/40 (95%) | 31/40 (77.5%) | 16/40 (40%) |
| EfficientAT mn04_as | 38/40 (95%) | 25/40 (62.5%) | 18/40 (45%) |
| PANNs MobileNetV2 | 36/40 (90%) | 25/40 (62.5%) | 18/40 (45%) |
| 3개 모델 평균 | 38/40 (95%) | 23/40 (57.5%) | 16/40 (40%) |

기준값은 경적 0.3, 나머지 0.5로 유지했다. 조정이나 학습은 하지 않았다.
평균 조합이 이 표본에서 아기 울음 감지를 줄였다. 모델 수 증가가 감지율
개선을 보장하지 않으므로 별도 보정용 데이터에서 기준값/결합 방식을 검토하고
독립된 검증 데이터로 확인해야 한다.

화재경보와 초인종은 ESC-50에 양성 음원이 없어 감지율을 산출하지 못했다.
둘의 결과는 0%가 아닌 미측정이다.

## 정답이 다른 음원에서의 감지

| 모델 | 화재경보 | 사이렌 | 아기 울음 | 초인종 | 경적 |
|---|---:|---:|---:|---:|---:|
| YAMNet | 1/214 | 2/174 | 1/174 | 0/214 | 1/174 |
| EfficientAT | 0/214 | 1/174 | 0/174 | 0/214 | 0/174 |
| PANNs | 2/214 | 0/174 | 0/174 | 0/214 | 1/174 |
| 3개 모델 평균 | 0/214 | 0/174 | 0/174 | 0/214 | 1/174 |

ESC-50은 중첩 소리 유무까지 정답으로 보장하지 않는다. 위 수치는 정답
분류가 다른 클립에서 해당 소리가 감지된 횟수이며, 실제 오탐인지 청취 검토는
하지 않았다. 시간당 오탐률로 환산하지 않는다. 0건도 일반 환경 무오탐을 뜻하지 않는다.

## 조건과 한계

- 공식 ESC-50 리비전 `33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6`.
- 대상 3종 각 40개 전체 + 나머지 47종에서 파일명순 첫 2개씩, 총 214개.
- 16 kHz로 리샘플링하되 음량 정규화 없이 입력. 1.95초 문맥,
  0.4875초 간격, YAMNet은 같은 시점의 마지막 0.975초를 사용.
- 완성된 창만 평가하고 끝부분을 패딩하지 않는다. 한 창이라도 기준값을 넘으면
  해당 클립 감지 성공. 모델 평균은 각 창에서 먼저 계산한다.
- YAMNet도 평균 조합의 첫 창 시점에 맞췄으므로 과거의 단독 YAMNet 측정치와
  조건이 다르다. 과거 수치와 직접 비교해 성능 변화를 주장할 수 없다.
- 소규모 탐색 검사이며 모델 사전학습 데이터와의 독립성은 확인하지 않았다.
- 실제 휴대전화, 거리/스피커/마이크 영향, 3초 알림, 배터리는 측정하지 않았다.

원시 클립별 점수, 모델/음원 SHA-256, 실행 환경과 집계는
[`report-five-sounds.json`](../tools/model_evaluation/report-five-sounds.json)에 보존했다.
재실행 방법은 [`평가 도구 안내`](../tools/model_evaluation/README.md)에 있다.
평가 도구의 창 분할·PCM 스케일·리샘플링·집계 테스트 4개가 통과했다.
